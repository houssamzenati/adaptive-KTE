# adaptive-KTE

Code for the updated projected adaptive kernel treatment effect test (`PADR-KTE`) under adaptive data collection.

## What is in this branch

- `projected_adaptive_kte.py`: corrected projected adaptive estimator used in the updated manuscript.
- `dr_kte_adaptive.py`: legacy variance-stabilized estimator (`VS-DR-KTE`), kept only for appendix-style comparisons.
- `paper_experiments/`: shared data-generation, evaluation, and plotting utilities.
- `scripts/`: readable entrypoints for each paper experiment.

The main-text experiments now use the chronological sample split required by the projected estimator. The old alternating-fold pipeline is not used for the main results anymore.

## Environment

```bash
conda create -n adaptive-kte python=3.9
conda activate adaptive-kte
pip install -r requirements.txt
```

If Matplotlib complains about cache permissions, set:

```bash
export MPLCONFIGDIR="$PWD/.matplotlib"
```

## Main-text experiments

Figure 1, failure of naive DR-xKTE under adaptive sampling:

```bash
python scripts/run_failure_example_dr_xkte.py
```

```bash
python scripts/run_main_synthetic_cosine.py
```

IHDP experiment:

```bash
python scripts/run_main_ihdp.py
```

dSprite experiment:

